3Prop emblems instead of faces

Each character becomes the object it carries, on a tint-coded disc. This solves the real problem: a bomb silhouette survives 18px in a way a face never will, and it sidesteps likeness entirely. Tint still carries identity, so two characters with similar props stay distinguishable. Fuu has no signature prop, so she is the test case — A keeps the object system with a flower, B breaks it with a figure silhouette. Pick one rule for the whole cast; mixing objects and figures is what makes an icon set feel unfinished.
